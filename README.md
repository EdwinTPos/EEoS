# EEoS
Accompanying code for the manuscript "A coherent signature of disturbance and recovery in tropical forests"

This repository contains all the necessary files for calculating the Ecological Equation of State and generating all the figures and results as presented in the manuscript "A coherent signature of disturbance and recovery in tropical forests". The first file, "01_EEoS_Analysis_2026.R" needs to be run within the self-contained directory. From there, subsequently all seperate files create each figure. 

Data is available in the repository, with the original source being:

Chazdon, Robin (2021). Tree abundance in eight 1-ha tropical forest plots in northeastern Costa Rica from 1997-2017 [Dataset]. Dryad. https://doi.org/10.5061/dryad.ncjsxksvr
